# Art-Directed Portfolio

## Principles
- Design for the owner's actual identity, audience, and projects.
- Establish one documented visual concept before implementation.
- Avoid generic AI-generated portfolio patterns and default template layouts.
- Use hierarchy, typography, whitespace, and composition to create distinction instead of decorative effects.
- Vary layouts intentionally; never make every section an identical card grid.
- Use real project assets and verified content only.
- Never invent metrics, testimonials, employers, clients, or results.

## Workflow
1. Inspect the existing repository, framework, and deployment.
2. Audit the current site at multiple viewport widths.
3. Write an evidence-based issue report before modifying code.
4. Document the visual direction, typography, colors, and layout rules.
5. Implement the redesign in small, reviewable steps.
6. Test responsive layouts, accessibility, links, and performance.
7. Compare before-and-after screenshots and report remaining issues.

## Quality gates
- No horizontal overflow at supported widths.
- Keyboard-accessible navigation and visible focus states.
- Reduced-motion support.
